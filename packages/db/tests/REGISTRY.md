Sumber: `docs/team/round1/qa.md` (R1, R3, R4, R6, R7, R10, R11, Lampiran A) dan peta ID S7 di `docs/superpowers/handoff/s7.md`. C9 ditambahkan di S9 (plan S9 Task 4, konkurensi satu kewajiban); qa.md hanya punya C1 sampai C8.

Pemeriksa: `pnpm test:registry` (`scripts/check-test-registry.ts`). Galat bila ID `aktif` dengan milestone <= M2 tidak punya tag, atau ada tag yang tidak ada di tabel ini.

## Format tag

- pgTAP: baris komentar `-- ID: B3, B6` di berkas `packages/db/tests/*.sql` (atau `[B4]` di deskripsi asersi).
- Vitest: `[B20]` di judul tes, berkas `*.test.ts(x)`.
- Playwright: `{ tag: ['@B20'] }`, berkas `*.spec.ts`.

## Status

- `aktif`: ada tes yang menutup ID ini; pemeriksa mewajibkan minimal satu tag (milestone <= M2).
- `belum`: ID sah tetapi tes bertag belum ada atau milestone-nya belum tiba; kolom Lokasi menyebut alasan.
- `tidak bisa dipetakan`: definisi sumber tidak ada di repo ini; tidak ada tes yang bisa diberi tag dengan jujur.
