# Design critique dan Delivery Gate S15

S15 Task 12. Antislop mode DURING; Delivery Gate dijalankan sebagai daftar periksa terhadap bukti visual 320/390/1280 px gelap dan terang, mengikuti pola S14 (`docs/design/s14-critique.md`). Bingkai yang dinilai: `docs/design/s15-bingkai.md` (`S15-TR1` sampai `S15-TR23`, daftar periksa design reviewer butir 1–13). Branch `feat/s15-trip-ui` (di atas `main` `f7836ca`, PR #40). Penilai: satu agen (Gemini/Antigravity) dari tangkapan layar yang dibuka langsung satu per satu plus audit otomatis per layar.

## Ringkasan

- **84 PNG** (14 layar × 320/390/1280 × gelap/terang), 18 tangkapan representatif dibuka dan dinilai langsung (fokus 320 px, nominal besar `Rp 12.345.678.900`, nama 60 huruf, gelap & terang, sheet dan dialog).
- **Temuan 2:** Blocker 0, Penting 1 (`S15-C1`, diperbaiki dan diverifikasi ulang dari tangkapan baru), Minor 1 (`S15-C2`, ditunda).
- **Audit otomatis 84 tangkapan (`_audit.jsonl`):** gulir horizontal = **0**, kata terlarang (`boncos`, `surplus`, `budget`, `Liburan`, `hutang`, `rumah tangga`, `!`, emoji) = **0**, `Rp 0` = **0**.
- **Budget JS rute (muat dingin nyata):** `/pribadi/trip` **148,3 kB**, `/pribadi/trip/[id]` **148,7 kB**, Beranda **157,4 kB** (tidak naik; sebelumnya 157,5), Transaksi **157,4 kB** (sebelumnya 157,6), Detail transaksi **153,4 kB** (sebelumnya 153,6) — semua jauh di bawah batas 162 kB. Prototipe `budget.spec.ts` 9/9 lulus tanpa perubahan.

## Metode

- **Skrip:** `apps/web/tests/e2e-ledger/screens-s15-trip.spec.ts` (aktif hanya dengan `SHOTS_DIR`; di luar `SHOTS_DIR` dilewati). Menjalankan: `SHOTS_DIR=/tmp/shots-s15 PW_CHROMIUM_PATH=/usr/bin/google-chrome AUTH_E2E_DATABASE_URL=... AUTH_E2E_ADMIN_URL=... pnpm --filter @dompetku/web exec playwright test -c playwright.ledger.config.ts --project=kosong tests/e2e-ledger/screens-s15-trip.spec.ts`.
- **Keluaran:** `/tmp/shots-s15/` (di luar repo, tidak di-commit), nama `{layar}-{lebar}-{tema}.png`.
- **Audit otomatis per tangkapan (`_audit.jsonl`):** `scrollWidth - clientWidth` (harus 0), kata terlarang S15, dan kemunculan `Rp 0`.

## Delivery Gate (daftar periksa bingkai 1–13 + antislop)

| Butir                                       | Hasil                                                                                                                                                                                                                                                                 |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 Salinan (kata terlarang, tanda seru)      | **Lulus:** audit 84 tangkapan = 0 kata terlarang, 0 tanda seru, 0 emoji; seluruh salinan cocok dengan "Salinan final S15" (`Trip`, `Masukkan`, `Keluarkan dari trip`, `Lebih Rp …`, `Sisa Rp …`, `{n} pengeluaran`).                                                  |
| 2 Tanpa `Rp 0`                              | **Lulus:** audit 84 tangkapan = 0 `Rp 0`; trip kosong menampilkan `Belum ada pengeluaran` (daftar) / `Belum ada pengeluaran di trip ini` (detail); anggaran kosong tanpa `Sisa`; rata-rata tidak tampil bila 0.                                                       |
| 3 Satu angka besar per layar                | **Lulus:** hanya total hero di Detail trip yang memakai ukuran angka besar; anggaran dan rincian lebih kecil; kartu tanpa bayangan; Beranda tidak ditambah kartu trip.                                                                                                |
| 4 Anggaran                                  | **Lulus:** bilah satu warna ruang (`bg-pribadi`/`bg-bersama`) di jalur `surface-2`, `role="progressbar"` + `aria-valuetext` (termasuk `Kurang dari 1 persen`), `Lebih` memakai ikon peringatan + kata + `warning` di kedua tema, catatan `Hanya pembanding…` terbaca. |
| 5 Fase dan status = ikon + teks             | **Lulus:** `Berlangsung` (`accent-text` + pesawat), `Akan datang` (kalender), `Selesai` (centang), `Diarsipkan` (arsip), `Di luar tanggal trip` (info), `Dari patungan` (info). Tanpa merah/hijau untuk fase.                                                         |
| 6 Angka cocok antar layar                   | **Lulus:** hero `Rp 2.250.000` = Σ Per kategori (`1.600.000 + 650.000`) = Σ Per hari (`1.250.000 + 650.000 + 350.000`) = baris daftar Trip; I6 diuji SQL/int/e2e (`@I6`).                                                                                             |
| 7 320 px                                    | **Lulus:** overflow = 0 di semua 84 tangkapan; 60 huruf dan `Rp 12.345.678.900` utuh; rentang tidak pecah di tengah tanggal; `DateInput` satu kolom di Tambah; Catat 320 px menampilkan nominal, kategori, Trip, Simpan sekaligus; `S15-C1` 390 px diperbaiki.        |
| 8 Target sentuh ≥ 44, fokus, nama aksesibel | **Lulus:** tombol 44/48 (`Keluarkan` 44×44 dengan `aria-label` memuat judul, `Pulihkan trip {nama}`, `Trip {nama}, ganti`, `Lepas dari trip {nama}`); fokus kembali ke pembuka/baris berikutnya; axe 0 pelanggaran serius di `e2e:ledger` dan `e2e:bersama`.          |
| 9 Ruang tertulis                            | **Lulus:** `Trip · Pribadi`/`· Bersama`, `SpaceTag`, judul sheet dan toast menyebut ruang; `Dicatat oleh` hanya Bersama ≥ 2 anggota (`e2e-bersama/zz-trip.spec`); kanari Pribadi 0 bocoran (`@B25`).                                                                  |
| 10 Pemilih Catat/Ubah                       | **Lulus:** saran otomatis K9 tampil dengan chip + `Lepas` + kalimat; disembunyikan untuk Kantor, Talangan, Pemasukan, transfer; `switchRuang` mengosongkan trip; Ubah melepas trip otomatis bila ganti ke Kantor (`catat-trip.test.tsx`, `zz-trip.spec.ts`).          |
| 11 Detail transaksi & Pindahkan             | **Lulus:** baris `Trip` dengan tautan ke Detail trip di `tr-detail-transaksi-320-dark` dan `1280-light`; `MoveSheet` menampilkan `Trip tidak ikut…`; patungan tanpa `Keluarkan`.                                                                                      |
| 12 Keadaan                                  | **Lulus:** kosong, tiga grup, terarsip, berlangsung/akan datang/selesai, normal/lebih/kosong, Tambah galat kolom, Ubah `Hapus anggaran`, `Masukkan`, dialog `Arsipkan`, Bersama dua anggota (e2e).                                                                    |
| 13 Hirarki dan konsistensi                  | **Lulus:** pola daftar = Kontak/Kategori; sheet = pola Tujuan; Beranda, Transaksi (baris), Rencana, dan prototipe tidak berubah.                                                                                                                                      |
| Budget JS                                   | **Lulus:** `/pribadi/trip` 148,3 kB, `/pribadi/trip/[id]` 148,7 kB, Beranda 157,4 kB, Transaksi 157,4 kB, Detail transaksi 153,4 kB (batas 162 kB); prototipe 9/9 lulus.                                                                                              |

## Tidak dipotret (dijaga tes otomatis)

- Sub-halaman `Pilih trip · Pribadi` (tangkapan awal `tr-catat-pilih` gagal karena pemilih skrip lama; diperbaiki di `screens-s15-trip.spec.ts`, perilaku dan a11y diuji di `catat-trip.test.tsx`).
- Keadaan memuat (`loading.tsx`), galat jaringan/loader (`TripFailed`, `TripDetailFailed`), 200+ pengeluaran terpotong, toast `Urungkan`, dan Bersama dua anggota (`Dicatat oleh` + `Dari patungan` + dialog Arsipkan dengan nama pasangan) — seluruhnya dicakup unit test (`trip-views.test.tsx`, `trip-sheet.test.tsx`) dan e2e (`e2e-bersama/zz-trip.spec.ts`).
