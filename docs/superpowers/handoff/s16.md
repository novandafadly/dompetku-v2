## Apa yang ditambahkan di S16

- **Basis data (`packages/db/migrations/0149_kalender_langganan_pdf.sql`, expand-only):**
  - `app.subscription_key(text)` (normalisasi deskripsi huruf kecil + spasi tunggal).
  - `app.subscription_dismissals` (PK `(space_id, desc_key, amount)`, RLS ENABLE+FORCE pola ruang, hanya baca + sisip via fungsi API).
  - `api.cashflow_calendar(p_space_id, p_days default 30, p_today default null)` (INVOKER STABLE, `assert_member`, `p_days` 1..90): saldo operasional dompet aktif hari ini dikurangi tagihan terbuka (`app.bill_schedule`, terlambat dihitung di hari ini) + proyeksi tagihan aktif yang belum dimaterialisasi (`least(day_of_month, akhir bulan)`), mengembalikan `opening`, `bills_amount`, `bills_count`, `overdue_count`, `closing`, `short`, `bills jsonb`.
  - `api.detect_subscriptions(p_space_id, p_today default null)` (INVOKER STABLE): pengeluaran biasa (`report_class = 'expense'`, kaki `main`) 180 hari terakhir dengan `(subscription_key(description), amount)` sama di >= 3 bulan berbeda dan transaksi terakhir <= 45 hari, menyaring tagihan aktif dan daftar abaikan, maks 20 saran; menyaring kategori/dompet arsip untuk prefill aman.
  - `api.dismiss_subscription(p_space_id, p_name, p_amount)` (DEFINER, idempoten, `app.now()`).
  - `api.export_entries(..., p_via text default 'csv')`: memperluas fungsi 0148 dengan `p_via in ('csv', 'pdf')` untuk audit `export` meta `{count, via}` sambil menjaga pemanggil 3 argumen lama tetap jalan.
- **Server & PDF (`apps/web/src/server/ledger/`):**
  - `pdf.ts`: penyusun PDF 1.4 murni TS tanpa dependensi pihak ketiga (Helvetica/WinAnsi, escape `\`, `(`, `)`, kontrol -> spasi, NBSP -> spasi, tanpa anotasi/JS/URI/lampiran, K9).
  - `ekspor.ts` (`exportLaporanPdf`) & `app/[ruang]/laporan/ekspor-pdf/route.ts`: satu transaksi membaca sumber SQL yang sama persis dengan Laporan (`period_trend`, `category_summary`, `excluded_summary`, `export_entries(..., 'pdf')`), berbagi `exportLimiter` (10/jam/user), header `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, `attachment`, prototipe `404`.
  - `kalender.ts` (`loadKalender`, `parseKalenderDays`): seluruh angka termasuk `total_bills_amount` dan `lowest_balance` dari SQL (`bigint`).
  - `langganan.ts` (`detectSubscriptionsTx`, `dismissSubscription`) + `_actions/langganan.ts` (`dismissSubscriptionAction`) terintegrasi ke `loadRencana`.
- **UI:**
  - `/[ruang]/rencana/kalender`: Server Component penuh tanpa JS klien baru, pemilih jendela 30/60/90 hari, ringkasan saldo operasional + total tagihan + saldo terendah + status `Kurang` (ikon + teks), catatan jujur "Pemasukan belum diproyeksikan", daftar jadwal harian. Tautan `Lihat kalender arus kas` di `Rencana > Tagihan`.
  - Kartu `Saran langganan` di `Rencana > Tagihan` dengan `Jadikan tagihan` (membuka `BillSheet` terisi awal `BillPrefill`) dan `Abaikan` (idempoten, kunci klik ganda).
  - Tombol `Ekspor PDF` sejajar `Ekspor CSV` di `/[ruang]/laporan` (pulau malas `ExportIsland`).
