## Yang sudah ada di S17

1. **Database (`packages/db/migrations/0150_ai_kuota.sql`, expand-only):**
   - Tabel `app.ai_usage (user_id, day, feature, used, updated_at)` — PK `(user_id, day, feature)`, FK `user_id` → `auth."user"(id) on delete restrict`, RLS ENABLE+FORCE (`own_read`/`own_write`), tanpa DELETE.
   - `api.ai_quota(p_feature default null)` (INVOKER STABLE) dan `api.consume_ai_quota(p_feature)` (DEFINER atomik): `parse` = 15/hari, `analysis` = 5/hari per user (reset 00:00 WIB via `app.today()`).
   - `migrate:down` ditolak saat `app.settings env = 'prod'`.
2. **Multi-penyedia `LlmProvider` (Claude & Gemini) tanpa SDK berat (`apps/web/src/server/ai/`):**
   - `provider.ts`: kontrak `LlmProvider`, validasi Zod ketat (`llmParseRawSchema`), pembuat prompt hemat & bebas bocor (`buildParsePrompt`, **B13**: hanya tanggal WIB, nama dompet spendable aktif ruang ini, nama kategori aktif ruang ini, dan 1 teks input maks 300 huruf).
   - `gemini.ts`: Google Gemini (`gemini-2.5-flash` bawaan, header `x-goog-api-key`, JSON mode, timeout 8 dtk).
   - `claude.ts`: Anthropic Claude (`claude-haiku-4-5-20251001` bawaan, header `x-api-key` + `anthropic-version`, Messages API, timeout 8 dtk).
   - `config.ts`: `LLM_PROVIDER=auto|gemini|anthropic|none` + `LLM_FALLBACK_PROVIDER=auto|gemini|anthropic|none` → bisa memakai Gemini saja, Claude saja, atau keduanya dengan failover otomatis (primer → cadangan).
   - `rules.ts` & `parse-entry.ts`: aturan dulu (0 kuota, < 1 ms, mendukung dompet alami tanpa `@` termasuk dompet berangka, `"2 hari lalu"`, kategori aktif) → fallback LLM hanya bila perlu; saat kuota habis atau LLM gagal, parser aturan tetap berjalan. **100% baca-saja pada `app.entries`.**
   - `eval-cases.ts` + `eval.test.ts`: 60 kasus nyata Bahasa Indonesia dengan gerbang akurasi **>= 90%**.
3. **UI `CatatSheet` ("Ketik cepat", mode nyata saja):**
   - Server Action `parseFreeTextAction` di `apps/web/src/app/[ruang]/_actions/catat-ai.ts` (`query('parseFreeTextAction', actionContext(ruang), ...)`, baca-saja, tanpa `refresh()`).
   - Bilah `Ketik cepat` (`S17-TB1`) di luar `<form>` `CatatSheet` (Enter/klik `Isi` tidak pernah auto-simpan) + banner pratinjau wajib konfirmasi (`S17-TB2`) + umpan balik galat/kuota habis (`S17-TB3`).
   - Mode prototipe tidak berubah; `CatatSheet` lazy-loaded → **0 byte** tambahan pada cold-load JS rute.

## Mengaktifkan Claude / Gemini di VM produksi (opsional)

Merge otomatis menerapkan migrasi `0150_ai_kuota.sql` tanpa langkah VM baru. Tanpa API key, `Ketik cepat` tetap berjalan penuh memakai parser aturan. Untuk menyalakan bantuan LLM di `/opt/dompetku/env/web.env` (lihat `infra/db-vm/deploy/web.env.example`):

- **Keduanya dengan failover otomatis (rekomendasi):** isi `GEMINI_API_KEY` dan `ANTHROPIC_API_KEY`, biarkan `LLM_PROVIDER=auto` dan `LLM_FALLBACK_PROVIDER=auto` (Gemini primer, Claude cadangan; ubah `LLM_PROVIDER=anthropic` bila ingin Claude primer).
- **Gemini saja:** isi hanya `GEMINI_API_KEY`.
- **Claude saja:** isi hanya `ANTHROPIC_API_KEY`.
- **Aturan saja (matikan panggilan luar):** biarkan kedua kunci kosong atau set `LLM_PROVIDER=none`.
