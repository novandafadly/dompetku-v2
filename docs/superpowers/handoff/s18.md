## Yang sudah selesai di S18 (M6 selesai)

1. **Foto struk terenkripsi AES-256-GCM tanpa OCR:**
   - **Database (`packages/db/migrations/0151_foto_struk.sql`, expand-only):** tabel `app.entry_attachments` (`space_id` restrict, `entry_id` on delete cascade, `uploaded_by` restrict, `ciphertext bytea`, `iv` 12 byte, `auth_tag` 16 byte, 3 indeks FK, RLS ENABLE+FORCE) + 4 fungsi API (`api.list_entry_attachments`, `api.get_entry_attachment`, `api.add_entry_attachment` atomik `FOR UPDATE` maks 3 per entri hidup, `api.delete_entry_attachment` hapus permanen). `migrate:down` ditolak saat `app.settings env = 'prod'`.
   - **Kriptografi & Route Handlers:** `apps/web/src/server/ledger/struk-crypto.ts` (AES-256-GCM + AAD `dompetku:receipt:v1:<spaceId>:<entryId>:<attachmentId>`, deteksi magic bytes JPEG/PNG/WebP tolak SVG/HTML/PDF, maks 2 MiB) + `apps/web/src/server/ledger/struk.ts` + `POST /[ruang]/transaksi/[id]/struk` & `GET|DELETE /[ruang]/transaksi/[id]/struk/[attachmentId]` (cek same-origin, batas 20/jam/user, `X-Content-Type-Options: nosniff`, `Cache-Control: private, no-store`, `Content-Disposition: inline; filename="struk.<ext>"`).
   - **UI Detail transaksi:** pulau malas `DetailStrukIsland` (`detail-struk.tsx` + `detail-islands.tsx`) pada `DetailReal` mode nyata (0 byte di prototipe).
2. **Analisis AI (`/[ruang]/analisis`):**
   - Memakai `LlmProvider` multi-penyedia (Google Gemini & Anthropic Claude, failover otomatis) dan kuota harian DB `analysis` (5/hari/user WIB dari `0150_ai_kuota.sql`).
   - **Privasi B13:** hanya mengirim angka agregat SQL ruang aktif (pemasukan, pengeluaran, selisih, sisa aman, dan maks 6 kategori pengeluaran teratas) — tidak pernah deskripsi transaksi mentah, dompet, kontak, atau ruang lain.
   - Server Action baca-saja `runAnalysisAction` (`_actions/analisis.ts`), halaman `/[ruang]/analisis`, dan tautan `Analisis AI` di `MenuSheet` mode nyata. Bila API key belum diisi atau kuota 5/5 habis, ringkasan angka SQL tetap tampil penuh dengan catatan jujur.
3. **PWA offline-baca & pembersihan cache wajib saat logout:**
   - `apps/web/public/sw.js` (dikecualikan dari `proxy.ts`, disajikan dengan `Cache-Control: no-cache, no-store, must-revalidate` & `Service-Worker-Allowed: /`): network-first `dompetku-pages-v1` untuk navigasi HTML ruang, cache-first `dompetku-static-v1` untuk aset statis publik; **tidak pernah** meng-cache non-GET, `/api/*`, `*/struk*`, `*/ekspor*`, redirect auth, atau RSC.
   - `PwaBridge` (`apps/web/src/app/[ruang]/_real/pwa-bridge.tsx`): Server Component bernonce CSP (0 byte JS klien) untuk registrasi `/sw.js` dan banner offline tenang `Sedang offline · Mode baca saja`.
   - `clearClientCaches()` (`features/shell/pwa-cache.ts`): dipanggil berlapis pada klik `Keluar` di `MenuSheet` dan saat mendarat di `/masuk?status=keluar` atau `?status=sandi-diganti` (`MasukReal`), menghapus seluruh `dompetku-pages-*` dan `sessionStorage`.

## Mengaktifkan Foto Struk & Analisis AI di VM produksi (opsional, 0 perubahan infra)

Merge otomatis menerapkan migrasi `0151_foto_struk.sql` tanpa langkah VM/volume baru. Di `/opt/dompetku/env/web.env` (lihat `infra/db-vm/deploy/web.env.example`):

- **Foto struk:** buat kunci 32 byte acak (`openssl rand -hex 32`), simpan di `RECEIPT_ENCRYPTION_KEY=` **dan simpan salinan cadangan di password manager** (kehilangan kunci membuat ciphertext struk lama tidak bisa didekripsi). Bila dibiarkan kosong, unggah foto struk nonaktif secara jujur.
- **Analisis AI:** memakai variabel LLM yang sama dengan S17 (`GEMINI_API_KEY` dan/atau `ANTHROPIC_API_KEY`, `LLM_PROVIDER=auto`, `LLM_FALLBACK_PROVIDER=auto`).
