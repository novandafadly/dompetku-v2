**Sesudah merge** (merge = deploy + migrasi 0109–0113 di produksi). Ikuti `docs/ops/runbook-s7-worker.md`; urutan wajib:

1. Buat 2 check Healthchecks (`dompetku-dq` `0 1 * * *`, `dompetku-jobs` `20 1 * * *`, zona `Asia/Jakarta`, grace 2 jam); simpan URL ping.
2. Pasang berkas (sesi VM): `deploy`, `compose.yml`, `postgres/pg_hba.conf` + `postgresql.conf`.
3. **Build ulang image postgres dan buat ulang kontainernya** (`docker compose build postgres && docker compose up -d postgres`), tunggu `healthy`, verifikasi `log_error_verbosity = terse` dan network `dompetku_worker_db` (172.25.0.0/16). **Ini harus SEBELUM `worker.env` dipasang**: tanpa `pg_hba.conf` baru worker ditolak `28000` dan deployer me-rollback rilis (kode 3).
