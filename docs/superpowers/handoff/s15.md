## Catatan rilis dan langkah pemilik

- **Tidak ada langkah VM baru untuk S15:** merge ke `main` = deploy + migrasi maju-saja `0146`–`0148` otomatis.
- **Jangan rollback image web ke pra-S15 sesudah ada trip:** `update_entry` web pra-S15 tidak mengirim `p_trip_id`, sehingga mengubah entri akan melepas tag trip diam-diam.
- **Sehari sesudah deploy:** cek `dompetku-dq` memastikan **DQ20 = 0** (bersama DQ08/DQ18/DQ19 S14).
- **Langkah VM tertunda dari S14** (bila belum dikerjakan): pasang egress worker (`docs/ops/runbook-s7-worker.md` "Pasang S14"), terapkan OpenWA `0.29.1` di VM lalu uji pairing WA.
