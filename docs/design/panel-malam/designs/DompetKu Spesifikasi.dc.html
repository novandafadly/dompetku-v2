Spesifikasi developer

Arah: Panel Malam (1b). Tema bawaan: gelap. DompetKu paling sering dibuka untuk cek cepat sebelum jajan, sering malam hari, dan lime di atas hampir-hitam membuat angka “Aman dipakai” langsung terbaca. Tema terang tersedia di Menu → Tampilan (Gelap · Terang · Ikuti sistem).

Huruf: Plus Jakarta Sans (Tokotype, Jakarta). Cocok dan saya pakai di semua layar: gratis di Google Fonts dan @fontsource/plus-jakarta-sans, jadi bisa dimuat lokal. Bentuknya geometris tapi hangat, kuat di 800 untuk angka besar, dan mendukung digit tabular (font-variant-numeric: tabular-nums). Muat 400, 500, 600, 700, 800 (subset latin), font-display: swap, fallback system-ui.

Ikon: tetap Phosphor, regular untuk navigasi, fill untuk keadaan aktif/status, bold untuk ikon kecil di tombol. Token CSS siap pakai ada di dompetku-tokens.css (Tailwind v4 @theme).

Token warna

Nama dari batasan.md dipertahankan; token tambahan ditandai pemakaiannya. Kontras dihitung WCAG 2.1 terhadap latar yang benar-benar dipakai. Teks 4,5:1, batas kontrol & fokus 3:1. Lime accent di tema terang hanya dipakai sebagai isi tombol (dengan teks on-accent + garis accent-edge), tidak pernah sebagai teks.

Catatan layout per breakpoint

320–599 (HP)
1 kolom, padding sisi 12 · header 66 px (judul ruang, pengalih, Menu) · tab bar 80 px + safe area · main = flex:1 overflow auto, jadi tidak ada konten di bawah bar · di < 360: tombol Catat di tab bar jadi ikon 48×48 dengan label di bawah, judul ruang di header disembunyikan secara visual (tetap ada di pengalih + aria)
600–1023 (tablet)
tab bar tetap · isi maks 720 px, padding 24 · tagihan + anggaran 2 kolom · Catat jadi dialog tengah 520
≥ 1024 (laptop)
sidebar 248 tetap, tab bar disembunyikan · header halaman: label “Ruang …” + judul 28 · isi maks 1000 px, grid 1,3fr / 1fr, jarak 20 · Transaksi: daftar + Ringkasan berdampingan (segmen disembunyikan) · Dompet: 3 kolom kelompok
Keyboard HP terbuka
pakai visualViewport: sheet menempel di atas keyboard; urutan tetap: judul ruang, nominal, chip (grid 2 baris, geser horizontal, ≥ 4 terlihat penuh, tanpa ikon kategori), dompet/tanggal, Simpan; mode keyboard dipadatkan (tanpa handle, gap 8, nominal 36, tombol 44), tinggi sheet ≤ 356 px
Gerak
sheet naik 200 ms ease-out, toast 160 ms; tanpa library animasi (CSS transition saja) · prefers-reduced-motion: semua transisi 0 ms, skeleton tanpa denyut
Privasi
Bersama tidak memuat data Pribadi sama sekali (bukan disembunyikan dengan CSS) · toast & dialog selalu menyebut ruang · Detail transaksi menampilkan SpaceTag

Aksesibilitas yang harus dijaga di kode

Target
semua kontrol ≥ 44×44, jarak ≥ 8 · tab bar 52 · keypad 52
Fokus
:focus-visible → outline 2 px var(--focus), offset 2 px, di semua elemen interaktif, termasuk baris transaksi dan chip
Status
selalu ikon + teks: “Lewat 3 hari”, “85% terpakai”, “Segera”, ✓ di ruang aktif
Nominal
format Rp 1.250.000, negatif −Rp (U+2212), tabular-nums; pembaca layar membaca “minus”
Bilah proporsi
role="img" dengan aria-label berisi keempat angka
